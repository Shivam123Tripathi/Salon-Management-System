# Salon Management System

A full-stack salon booking and management project with:
- **Spring Boot backend** (REST APIs, auth, appointments, payments, notifications)
- **Android app** for customers/admin workflows

## Tech Stack
- Java 17, Spring Boot, Spring Security, JPA, Flyway, MySQL
- Android (Java), Gradle

## Quick Start
1. Set required environment variables (DB/JWT and optional service keys).
2. Run backend:
   - `mvn clean spring-boot:run`
3. Open Android project from `salon-app` in Android Studio and run the app.
